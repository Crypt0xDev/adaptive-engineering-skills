## What is it?

A Claude Code plugin with 101 software engineering skills organized in 9 categories. Before proposing anything, Claude **looks at your project's real context** and picks the simplest solution that works.

## Install

```
/plugin marketplace add Crypt0xDev/adaptive-engineering-skills
/plugin install adaptive-engineering@crypt0xdev
```

## Structure

```
skills/
├── engineering/    17 skills — roles and technical decisions
├── quality/        14 skills — code review, testing and simplification
├── design/          3 skills — UI, UX and frontend
├── devops/          5 skills — CI/CD, deploy and git workflow
├── security/        2 skills — security and hardening
├── workflow/        8 skills — process, specs and documentation
├── optimization/    4 skills — performance and token savings
├── omniroute/      45 skills — multi-provider LLM gateway
└── memory/          3 skills — persistent memory
```

## Philosophy

```
Understand → Analyze context → Evaluate complexity → Simplest solution → Justify
```

> SOLID, DDD and patterns are not fixed rules: use them if the project calls for it.
> **Code quality and security, always.**
